# Dashboard Widget Rearrangement UI -- Design Spec

Drag-and-drop widget rearrangement system for the dashboard.
- Grid layout: CSS Grid with configurable columns
- Drag: HTML5 drag-and-drop API with ghost preview
- Drop zones: highlighted areas with pulse animation
- Persistence: save layout to backend/localStorage
- Accessibility: keyboard reorder mode (arrow keys)
- States: default, dragging, drop-target, saving, saved
