# Branding Preview Page -- Design Spec

Live preview page for merchants to visualize their brand pack settings.
- Layout: split view -- controls (left 40%) + preview (right 60%)
- Preview: mock invoice/email/page with live brand colors/logo
- Controls: color pickers, logo upload, font selector
- Real-time: instant preview updates on control change
- Accessibility: all controls keyboard accessible
- States: loading, empty, preview-ready, saving
