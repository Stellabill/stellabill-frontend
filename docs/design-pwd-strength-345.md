# Password Strength Meter Design

## Real-time assessment
NIST SP 800-63B compliant. Color-coded bar (red→orange→yellow→green).

## Scoring
- Length: <8=0, 8-11=1, 12-15=2, 16+=3
- Variety: lowercase+uppercase+digits+specials (1pt each)
- No common patterns (+1pt)
